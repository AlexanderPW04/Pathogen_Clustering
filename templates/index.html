Integrated Genomic Surveillance

One analysis for two kinds of genomic evidence: individual (consensus) sequences and pooled samples such as wastewater. Both are placed on the same verified reference-genome positions, so variants can be compared across sources, over time, and among locations. Results are screening signals; they do not confirm transmission, an outbreak, or the lineage of a mixed sample.

How the analysis works

MAFFT aligns sequences within each pathogen and gene/segment group before genetic distances are calculated. With a reference FASTA, each sequence is also aligned to the reference so its differences receive true 1-based reference positions.

When metadata has a location name but no coordinates, GeoNames may estimate them. These place coordinates can be approximate. State-only names such as USA: ND are too coarse for the kilometer cutoff or same-location fallback; their precision is reported in the pairwise output.

Genomic regions come first from metadata, then explicit FASTA descriptions. MAFFT aligns only samples with the same resolved pathogen and region. An unknown region is an error unless you explicitly confirm that every sequence is a complete genome of one pathogen.

Pooled variant tables list only the variants that were called. A variant missing from a pooled sample is "coverage unknown", never 0%, unless a per-position depth table shows the position was covered.

Step 1 · Upload your files

Select every file at once: individual sequences, their metadata, a reference genome, pooled variant calls, and any optional tables. The next step shows what each file was recognized as, so you can correct it before anything runs.

Accepted file formats
  • Sequences: FASTA (.fasta, .fa, .fna), optionally gzip-compressed (.gz). One sequence = possible reference genome; several = individual sequences.
  • Tables: CSV, TSV/TXT (tab-separated), XLSX (first sheet); CSV/TSV may be .gz. Column names are matched flexibly (for example Sample / Sample_ID / SampleName, Date / Collection_Date, Lat / Latitude, AF / Frequency, DP / Depth).
  • Pooled variant calls: standardized SNV tables, combined iVar variant tables, the Fontenele et al. (2021) supplementary SNV workbook, and SNV VCF files (.vcf, .vcf.gz) with allele depths or frequencies.
  • Not accepted as results: raw reads (FASTQ) and read alignments (SAM/BAM/CRAM). Process them first with the optional offline workflow; then upload the variant table or VCF.
