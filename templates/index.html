Integrated Genomic Surveillance

One analysis for two kinds of genomic evidence — individual sequences (Sprint 2) and pooled sequencing results such as wastewater (Sprint 3) — connected on one reference genome, with optional AI metadata enrichment (Sprint 4). Results are screening signals; they do not confirm transmission, an outbreak, or the lineage of a mixed sample.

Follow one shared variant: {{ story.key }}

  1. Reference nucleotide. Position {{ story.position }} of reference {{ story.reference }} is {{ story.ref }}.
  2. Individual sequences (Sprint 2). {{ story.individual_count }} individual sequence(s) have {{ story.alt }} at that position after MAFFT places them on the reference: {{ story.individual }}. Each is one observed base.
  3. Pooled samples (Sprint 3). {{ story.pooled_count }} pooled sample(s) kept after quality control report {{ story.ref }}>{{ story.alt }} there, at frequencies {{ story.frequency_range }}: {{ story.pooled }}. Each is a share of sequencing reads, a different kind of measurement.
  4. Classification. Same reference, same position, same change in both sources, so the variant is {{ story.category }}.
  5. Time and place. First pooled report {{ story.first_pooled }}; first individual sequence {{ story.first_individual }}{% if story.days is not none %} ({% if story.days < 0 %}pooled {{ -story.days }} day(s) earlier{% elif story.days > 0 %}individual {{ story.days }} day(s) earlier{% else %}same day{% endif %}){% endif %}; {{ story.window_pairs }} individual–pooled pairs fall within the cross-source date window. Individual sequences come from {{ story.individual_places }}; pooled reports from {{ story.pooled_places }}{% if story.km is not none %}; nearest distance {{ story.km }} km{% else %}; no kilometer distance can be computed because the sites have no precise coordinates{% endif %}.

A shared variant shows that both kinds of surveillance saw the same nucleotide change. It does not show that the same infections, people, or lineage were sampled, or which source saw it first for a reason.
