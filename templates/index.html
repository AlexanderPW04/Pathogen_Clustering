Outbreak Cluster Detector

This prototype combines pathogen genomic similarity with collection date and geographic information to flag potential outbreak clusters. Results are screening signals and do not confirm transmission or an outbreak.

MAFFT aligns sequences within each pathogen and gene/segment group before genetic distances are calculated.

When metadata has a location name but no coordinates, GeoNames may estimate them. These place coordinates can be approximate. State-only names such as USA: ND are too coarse for the kilometer cutoff or same-location fallback; their precision is reported in the pairwise output.

Genomic regions come first from metadata, then explicit FASTA descriptions. MAFFT aligns only samples with the same resolved pathogen and region. An unknown region is an error unless you explicitly confirm that every sequence is a complete genome of one pathogen.

Run analysis

1. Genomic sequences Upload nucleotide sequences downloaded from a genomic database such as NCBI Virus.
2. Sample metadata Upload metadata containing accession, pathogen, collection date, location, and host/source. A gene/segment column is optional when FASTA descriptions identify the region.
3. Genomic-region selection

The example uses explicitly synthetic sequences and sample records, not NCBI records or real outbreaks. It uses your threshold settings and runs the same MAFFT-backed pipeline. One example record has a real place name but synthetic sample data and no coordinates so GeoNames can be demonstrated when configured.

Thresholds are prototype settings, not universal biological outbreak definitions.
