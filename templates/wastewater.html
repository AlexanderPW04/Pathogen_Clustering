Wastewater Surveillance

This mode summarizes observed SNVs in pooled wastewater samples. It is population genomic surveillance, not outbreak confirmation or individual-genome lineage assignment. A mutation missing from a table is not confirmed absent when coverage is unknown.

Upload processed SNV calls

Upload Fontenele et al. (2021) Supplementary Table 2 (mmc2.xlsx) directly, or use the documented standardized CSV/XLSX columns. The paper's reference genome is NC_045512.2; that label is assigned only to the recognized published table. This page does not run MAFFT or the Sprint 2 clustering pipeline.

Metadata joins on Sample_ID and can supply Collection_Date and Location_Name when those are missing in the SNV table. The published table already includes dates and locations. Upload limit for this mode: 3 MB for the SNV file.
