How this works

Three project sprints feed one analysis. Each can run on its own; they connect wherever the data allow.

Sprint 2 · Individual sequences FASTA sequences + sample metadata→ MAFFT alignment→ Genetic p-distance, dates, places (GeoNames)→ Related-sample screening
Sprint 3 · Pooled sequencing (for example wastewater) Pooled sample→ Sequencing reads→ Reference alignment and variant calling (done before upload, offline)→ Processed SNV table (you upload this)→ Frequencies, depth, quality, trends, PCoA
Shared reference genome = the connection Individual sequences are placed on the same numbered reference positions as the pooled variant calls. Each variant is then classed as shared, individual only, pooled only, unresolved (no usable coverage, so unknown) or incomparable (references not verified as the same).
Sprint 4 · Optional AI metadata enrichment Sample identifiers→ Linked publications (NCBI, PubTator)→ Claude reads relevant passages (only when enabled)→ Quotations checked; you approve→ GeoNames; dates and distances updated
Why the files differ but the results connect
  • An individual sequence is one genome per sample, so each reference position has one observed base.
  • A pooled sample mixes many genomes, so each position has an allele frequency and a read depth.
  • They are different measurements. They are compared only where both sit on one verified reference, by position and nucleotide change.
  • A missing pooled row is not 0%: without coverage information the result is "unknown".
  • Either source can be analyzed alone; one being unavailable never stops the other.

Technical notes

MAFFT aligns sequences within each pathogen and gene/segment group before genetic distances are calculated. With a reference FASTA, each sequence is also aligned to the reference so its differences receive true 1-based reference positions. MAFFT is for individual or consensus sequences; it does not process pooled short reads.

When metadata has a location name but no coordinates, GeoNames may estimate them. These place coordinates can be approximate. State-only names such as USA: ND are too coarse for the kilometer cutoff or same-location fallback; their precision is reported in the pairwise output.

Genomic regions come first from metadata, then explicit FASTA descriptions. MAFFT aligns only samples with the same resolved pathogen and region. An unknown region is an error unless you explicitly confirm that every sequence is a complete genome of one pathogen.

Pooled variant tables list only the variants that were called. A variant missing from a pooled sample is "coverage unknown", never 0%, unless a per-position depth table shows the position was covered.
